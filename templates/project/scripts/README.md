# scripts

Kit scripts copied by scaffold.sh. Do not edit them in the project; refresh them from the kit.
`start.sh` next REQ / bug / status / check, `loop.sh` implement-and-test loop, `gate.sh` the quality gate, `doclint.sh` documentation rules,
`pr.sh` open and merge PRs, `req_status.sh` REQ ledger, `autopilot.sh` unattended runs,
`dashboard.py` live progress page (`python3 scripts/dashboard.py`, add `--lan` for your phone). Each has `--help`.
