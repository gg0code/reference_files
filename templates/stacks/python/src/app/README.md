# app

The application. Start here:
`main.py` builds the app, `config.py` holds every setting, `shared/` is code used by every feature,
`features/<area>/` holds one feature each (routes, service, repository, models, templates),
`templates/` the page layout and the UI kit, `static/` CSS and JavaScript.
Where a change goes: docs/02-architecture.md section 3a.
